一点点关于我

我是一名普通但爱折腾的工科生。第一次用 <h1> 把名字显示在浏览器里的时候， 就觉得「写几行字、刷新一下就能看到结果」这件事很神奇。后来学了 CSS，才开始明白 结构与表现分离的意义；再往后接触 JavaScript，页面终于可以回应我的点击。

这学期的目标很朴素：把 语义化标签、表格与表单、Flex / Grid 布局、原生 DOM 操作 练到不用查文档也能写出来，然后独立完成几个能拿得出手的小项目。

写过的课程项目和小工具都开源在 GitHub（@haomiaoyan） 上，比如分子宇宙 MolCosmos、NEUROATLAS；也习惯把踩过的坑顺手写成 README。

把复杂的东西讲清楚，把简单的东西做漂亮。 —— 我给自己写前端笔记时定下的小原则

技能条的宽度是这样被「唤醒」的：

function fillSkills(el) {
  const level = el.dataset.level;
  el.style.width = level + '%';
}
document.querySelectorAll('.skill-fill')
        .forEach(fillSkills);

其中 level 表示目标百分比；参考 W3School JS 教程。
